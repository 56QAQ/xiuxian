# 版本规划

## v0.1「初入仙途」（当前）
可玩的纵向切片：捏人 → 大地图 → 修炼 / 宗门 / 遭遇 → 秘境搜打撤 → 存档。详见 GDD §12。

## v0.2「道基初成」
- **战斗深化**：格挡/拼刀（同时出手的近战互相弹开）、空中连段、处决（韧性崩溃的敌人可被处决）、更多武器模组（扇、旗、双剑、法杖）。
- **法诀扩展**：法诀可组合“诀印”词条（如：飞弹 + 分裂 / 追踪 / 爆炸），形成真正的构筑维度。
- **本命法器**：可成长、可温养的法器，随境界进阶外观变化。
- **阵法实装**：阵盘可在洞府布置（修炼加成、防御）或在战斗中临时布阵（困阵、杀阵）。
- **灵植与炼丹小游戏**：火候控制、灵植杂交。
- **地形破坏升级**：体素建筑可被整体摧毁并留下废墟；大型法术永久改变地形（存档保存）。

## v0.3「金丹大道」
- **更多区域**：青州之外的中州、北原、南疆，跨区域传送阵。
- **势力战争**：宗门之间的冲突事件，玩家可参与宗门大比、护山大阵防守。
- **魔道线**：可加入血煞宗，走魔修路线（夺舍、血祭、魔功），正邪声望体系。
- **NPC 深化**：NPC 之间也会结交、结仇、结为道侣、收徒；NPC 会主动来找玩家（寻仇、求助、邀约）。
- **同伴系统**：道侣与弟子可随行，拥有独立 AI 与装备。

## v0.4「元婴化神」
- **心魔与天劫**：大境界突破时的心魔幻境战斗、雷劫战斗（可借助法宝与阵法硬抗）。
- **洞天福地**：可经营的个人小世界（灵脉、药园、傀儡、弟子）。
- **高阶秘境**：多层秘境、首领战、团队型秘境（与 NPC 组队）。
- **寿元与传承**：坐化后可由弟子/后人继承部分遗产继续游戏。

## 技术债与持续工作
- 手柄支持与键位自定义界面。
- 大地图 NPC 的日程与寻路（目前为锚点附近闲逛）。
- 本地化框架（目前中文硬编码于数据与界面）。
- 音乐与音效替换为专业制作资源；角色与建筑模型可逐步替换为手工体素资源（.vox 导入）。
- 性能：角色网格合批与 LOD、地形网格多线程与贪心合并、战斗特效对象池。
