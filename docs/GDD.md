# 《问道长生》游戏设计文档 (GDD)

> 版本：v0.1「初入仙途」 · 引擎：Godot 4.4+（验证于 4.4.1 / 4.7.2） · 题材：修仙开放世界 RPG
> 参考：《造化仙缘》《觅长生》（修仙沙盒与人际羁绊）、《装甲核心4》（高速第三人称战斗）、塔科夫式“搜打撤”

---

## 1. 核心体验

玩家是一名刚踏入仙途的修士，在广袤的修仙世界中**自由探索**：修炼破境、拜入门派、闯荡秘境、结交或袭杀其他修士。

四根支柱：

| 支柱 | 玩家感受 | 系统 |
|---|---|---|
| **问道** | 每一次突破都是质变 | 境界、修炼/闭关/丹药/炼化/战斗感悟 |
| **斗法** | 高速、流畅、有打击感的斗法 | AC4 式三人称战斗、五行构筑、场景破坏 |
| **机缘** | 险中求富贵，贪婪与撤离的抉择 | 秘境搜打撤、品阶掉落、有限储物袋 |
| **因果** | 每个修士都有名字、立场与记忆 | NPC 羁绊、门派声望、业力、随机遭遇 |

## 2. 世界观

- **天元界·青州**：一片被五大宗门割据的土地，中心为散修聚集的**青云坊市**。
- 五大宗门各据一方，分别对应五行：

| 宗门 | 五行 | 地貌 | 战斗风格 | 生产技艺 | 宗门色 |
|---|---|---|---|---|---|
| 天剑宗 | 金 | 北部雪峰 | 暴击、流血 | 炼器 | 银白/金 |
| 青木谷 | 木 | 东部古林 | 回复、中毒 | 灵植 | 青绿 |
| 玄水阁 | 水 | 南部湖泽 | 控制、灵力 | 制符 | 靛蓝 |
| 离火殿 | 火 | 西部赤岩 | 纯粹攻击 | 炼丹 | 赤红 |
| 厚土宗 | 土 | 西南台地 | 护盾、减伤 | 阵法 | 土黄 |

- 魔道 **血煞宗** 暗中活动，是劫修与恶修的主要来源（v0.1 不可加入）。

## 3. 角色创建（捏人）

### 3.1 外貌（全部可自由决定，实时预览体素模型）
- 性别、身高、体型（纤细 ↔ 健壮）、头身比
- 发型：双马尾 / 高马尾 / 长直发 / 短发 / 道髻 / 披发
- 发色、瞳色、肤色（调色板 + 自定义）
- 眼型、眉型、额心花钿
- 身体部件：兽耳（狐/猫/无）、精灵耳、兽尾、龙角
- 初始服饰配色

### 3.2 灵根（消耗天赋点）
灵根数量决定修炼速度与单系强度，占比由玩家用滑条分配：

| 灵根 | 点数消耗 | 修炼速度 | 说明 |
|---|---|---|---|
| 天灵根（单） | 6 | ×2.0 | 单系纯度加成 +25% |
| 双灵根 | 3 | ×1.5 | 两系交叉构筑 |
| 三灵根 | 1 | ×1.1 | |
| 四灵根 | 0 | ×0.8 | |
| 五行杂灵根 | -2（返还） | ×0.6 | 获得“五行轮转”：相生链加成 |

### 3.3 先天属性与天赋（购点）
- 初始 **12 点**天赋点。
- 五项先天属性：**根骨**（生命/防御/突破）、**悟性**（修炼/感悟/学习）、**神识**（灵力/法术/搜索/锁定距离）、**身法**（速度/推进效率/暴击）、**气运**（掉落品阶/奇遇）。每项基础 5，提升 1 点消耗 1 天赋点，上限 10。
- 天赋：正面天赋消耗点数，负面天赋返还点数（通常附带代价与些许补偿）。详见 `data/talents.json`。
- 出身：散修 / 世家子弟 / 山野村童 / 宗门杂役，决定初始物品、灵石与起始关系。

## 4. 境界与修炼

### 4.1 境界
| 大境界 | 小境界 | 寿元 | 质变（解锁） |
|---|---|---|---|
| 炼气 | 一层~九层 | 120 | 基础斗法 |
| 筑基 | 初/中/后/圆满 | 220 | **御空**：可悬停飞行；法诀槽+0 |
| 金丹 | 初/中/后/圆满 | 500 | **第五法诀槽**、金丹爆发（大招） |
| 元婴 | 初/中/后/圆满 | 1000 | 元婴出窍：濒死时保命一次 |
| 化神 | 初/中/后/圆满 | 2000 | 领域 |

- 小境界提升：属性成长（数值）。
- 大境界突破：需修为圆满 + 突破判定（基础成功率 + 根骨 + 丹药 + 地点），失败则受伤（修为倒退、虚弱状态）。
- **境界压制**：每差一个大境界，伤害 ±30%。

### 4.2 修为来源
| 方式 | 说明 |
|---|---|
| 打坐修炼 | 实时进行，时间流速加快；洞府/宗门闭关室/灵脉有倍率 |
| 闭关 | 选择时长（天/月/年），时间跳跃，一次性获得大量修为；可能触发顿悟或心魔 |
| 战斗感悟 | 击败/切磋修士与妖兽获得修为，越阶战斗收益越高，有几率“顿悟”提升法诀熟练度 |
| 服食丹药 | 立即获得修为，累积**丹毒**降低后续药效，丹毒随时间消退 |
| 炼化灵物 | 炼化灵石、妖丹、灵草等；与灵根同属性的灵物效率更高 |

修炼速率 = 境界基础 × 主修功法倍率 × 灵根倍率 × (1 + 悟性加成) × 地点倍率 × 天赋。

## 5. 五行构筑

### 5.1 五行特性
| 五行 | 长处 | 状态 |
|---|---|---|
| 金 | 暴击率、暴击伤害 | **流血**：持续伤害，目标高速移动时伤害翻倍 |
| 木 | 生命回复 | **中毒**：降低目标攻击、防御、移速 |
| 水 | 灵力回复 | **束缚**：减速，满层后定身 |
| 火 | 纯粹攻击力 | **灼烧**：持续伤害并抑制护盾回复 |
| 土 | 护盾回复、伤害减免 | **震慑**：大幅削减韧性，更容易打出硬直 |

- 灵根占比 p 决定该系的被动加成（线性）与该系法诀/法器的威力倍率（0.6 + 0.8p）。
- 天灵根额外 +25% 纯度加成；多灵根依赖**相生共鸣**：同时装备相生两系（金→水→木→火→土→金）的法诀，获得共鸣效果。
- 相克：攻击方元素克制目标主元素，伤害 +20%。

### 5.2 构筑维度
1. **法器**：武器（决定近战动作模组：剑/刀/枪/拳）、法衣、饰品×2，有品阶与随机词条。
2. **功法**：主修 1 + 辅修 2。主修决定修炼速度与灵气弹属性；辅修提供被动。熟练度：入门→小成→大成→圆满。
3. **法诀**：4 个快捷槽（金丹+1），类型包括飞弹、爆发、天降、突进、护体、增益、领域、召唤。随使用提升熟练度。

## 6. 战斗系统（AC4 式）

### 6.1 操作
| 操作 | 键位 |
|---|---|
| 移动 | WASD |
| 跳跃 / 上升 | Space（空中按住上升，消耗灵力） |
| 下降 | Ctrl |
| 疾行（Boost） | Shift 按住 |
| 瞬步（Quick Boost） | E / 鼠标侧键 |
| 近战普攻 | 鼠标左键（连段，锁定时突进） |
| 灵气弹 | 鼠标右键（按住蓄力） |
| 法诀 | 1~5 |
| 锁定 / 切换目标 | 鼠标中键 / Tab |
| 服用丹药 | Q |
| 金丹爆发（金丹期） | G |
| 交互 | F |
| 背包 / 角色 / 功法 / 宗门 / 地图 | B / C / K / J / M |
| 打坐 | T |

### 6.2 资源
- **生命**：归零即死亡（秘境中丢失储物袋）。
- **护体灵光（护盾）**：先于生命承伤，脱战 3 秒后回复；被击破时短暂硬直。
- **灵力**：法诀、灵气弹、疾行、瞬步、飞行共用。耗尽进入“灵力枯竭”（短时间无法推进，回复变慢）——鼓励节奏管理。
- **韧性**：被削空时硬直。

### 6.3 屏幕中央 HUD
- 中央准星外为一枚玉璧：左弧朱砂笔触为生命、右弧青色灵液为灵力，外圈八卦为护体灵光，下方状态以印章显示，上方为境界与锁定信息。
- 整个 HUD 簇随角色运动反向漂移（高速推进时明显偏移），营造机动感。
- 锁定框、命中标记、伤害数字、受击方向提示。

### 6.4 打击感
顿帧（hitstop）、镜头震动、受击闪白、击退与硬直、体素碎屑粒子、伤害跳字、音效分层。

### 6.5 场景破坏
- 体素可破坏物（岩石、石柱、墙体、树木、箱子）：命中处体素被剔除并化为物理碎块，失去支撑的部分整体坠落。
- 地形：强力法诀可在地面炸出弹坑。

## 7. 门派

- 声望阶位：记名弟子 → 外门弟子 → 内门弟子 → 核心弟子 → 真传弟子（部分需境界门槛）。
- **贡献点**：任务获得，用于宗门商店（功法玉简、法诀、丹药、法器）。
- **任务堂**：猎杀、采集上交、秘境寻物、除魔、切磋。
- **传功长老**：学习本门功法/法诀（按阶位解锁）。
- **生产技艺**：本门特色（炼器/灵植/制符/炼丹/阵法），配方与熟练度。
- **宗门人脉**：掌门、长老、执事、同门师兄师姐（NPC，可建立羁绊）。
- 同一时间只能加入一个宗门；叛出宗门会损失声望。

## 8. 秘境（搜打撤）

1. 在大地图找到秘境入口进入；秘境按境界分级。
2. 秘境为程序生成的区域：若干区域/浮岛，散布**容器**（宝箱、药圃、矿脉、修士遗骸），以及妖兽、傀儡与**其他寻宝修士**。
3. **搜索**需要时间（神识越高越快），物品逐个显现，品阶以颜色区分：凡（灰）、灵（绿）、玄（蓝）、地（紫）、天（橙）、仙（红）。
4. **储物袋**为网格背包（物品占格、可旋转），容量有限，需要取舍。
5. **撤离点**：站在撤离阵中读条撤离；秘境会随时间崩塌。
6. 死亡：失去储物袋内全部物品（**本命空间** 2×2 格物品保留）。

## 9. 遭遇与羁绊

- 世界中有持久存在的 NPC 修士：姓名、宗门、境界、立场（正/中/邪）、性格、外貌、装备与记忆。NPC 会随时间修炼、突破、衰老乃至陨落。
- 好感度 -100~100，关系：陌生 → 相识 → 好友 → 知己；特殊：道侣、师徒、仇敌。
- 交互：交谈、切磋、赠礼、交易、请教、结交、袭杀。
- 随机遭遇：
  - **同道切磋**：点到为止的比斗，胜负都有感悟。
  - **劫修拦路**：交出财物、拒绝迎战或瞬步逃离。
  - **天材地宝出世**：地图出现光柱，多名修士赶来争夺，先完成采集者得宝。
  - **妖兽袭击 / 遇险求救**：出手相救大幅提升好感。
  - **玩家袭杀**：可攻击任何修士夺其储物袋，增加业力；被目击会损失声望、结下仇怨。

## 10. 时间与存档
- 世界时间：天元历，年/月/日/时。大地图 1 分钟 ≈ 1 个时辰。闭关等行为会跳跃时间，寿元耗尽即坐化（游戏结束）。
- 存档：JSON，存于 `user://saves/`。秘境内不可存档。

## 11. 美术方向
- 高精度体素角色（每米 80 体素，头部 32³），见参考图：红发双马尾、狐耳、金红战甲、旗枪。逐体素材质（布、皮肤、头发、金、钢、宝石、玉……）决定光泽与高光。
- 世界：1 米方块地形，32×32 像素方块材质（鱼鳞瓦、瓦当、彩画梁枋、窗棂、祥云石雕等）；五大区域配色鲜明；建筑为中式宫殿（红柱、白墙、黛瓦、金饰）。
- 氛围：水墨远山天空、分层雾与调色 LUT、按区域的环境粒子（花瓣、雪、灰烬、萤火、灵光）；夜间灯笼与窗棂亮起。
- 特效：法阵、符箓、剑气月牙、五行元素弹体；色彩以五行配色为准，亮场景中仍保持元素色。
- 界面：宣纸、漆墨、朱印、书法字体；HUD 为玉璧与八卦。
- 光照：Forward+，柔和阴影、SSAO/SSIL、辉光、体积雾、AgX 色调映射；兼容渲染器自动降级。
